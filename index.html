What I Have Learned This Week


This week has been a productive learning journey in web development and software tools. I explored HTML, CSS, GitHub, Git, Linux commands, and how to install Node.js. Each topic helped me understand how modern websites and development environments work together.

Learning HTML

I started by learning HTML (HyperText Markup Language), which is the foundation of every website. I learned how to structure a webpage using elements such as headings, paragraphs, images, links, tables, forms, and lists. I also understood the importance of semantic tags like

  • header
  • main
  • section
  • footer
in organizing web content properly.

One of the most interesting things I learned was how HTML provides the structure of a website while other technologies handle styling and functionality.

Learning CSS

After HTML, I moved to CSS (Cascading Style Sheets). CSS helped me understand how websites are styled and made visually attractive. I learned how to:

  • Change colors, fonts, and layouts
  • Use classes and IDs to target specific elements
  • Create responsive designs that work on different devices
  • Implement animations and transitions for better user experience

I also learned about position: relative, how layouts adjust on different screen sizes, and how CSS improves user experience.

Learning GitHub and Git

GitHub and Git are essential tools for version control and collaboration in software development. I learned how to:

  • Initialize a Git repository
  • Commit changes and track modifications
  • Push code to a remote repository on GitHub
  • Collaborate with others by creating pull requests

Understanding these tools is crucial for managing code effectively and working in teams.

Overall, this week has been a great introduction to web development and software tools. I am excited to continue learning and applying these skills in future projects.
